# 결정 기록

이 문서는 구조 변경, 하네스 규칙 변경, 예외 승인을 기록한다. 새 기록은 최신 항목이 위에 오도록 추가한다.

## Entry Template

```markdown
## YYYY-MM-DD - [결정 제목]

- 결정:
- 이유:
- 영향:
- 승인:
- 검증:
```

## 2026-07-07 - AI 작업 하네스 0단계 도입

- 결정: 루트 `AGENTS.md`와 `docs/harness` 문서 세트를 추가해 AI 작업자가 따라야 할 문서 기반 하네스를 만든다.
- 이유: 이후 코드 변경이 임의의 구조 변경으로 번지지 않도록 작업 전 확인 문서, 구조 계약, 검증 기준을 고정하기 위해서다.
- 영향: 작업자는 코드 수정 전 하네스 인덱스와 관련 계약 문서를 읽어야 한다.
- 승인: 사용자가 AI 작업 하네스 방식의 0단계 MD 구조 계획 구현을 요청했다.
- 검증: 문서 링크, 현재 백엔드 구조와의 일치 여부, 사용 시나리오를 확인한다.
