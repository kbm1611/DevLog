# 결정 기록

이 문서는 구조 변경, 하네스 규칙 변경, 예외 승인을 기록한다. 새 기록은 최신 항목이 위에 오도록 추가한다.

## Entry Template

```markdown
## YYYY-MM-DD - [결정 제목]

- 결정:
- 이유:
- 영향:
- 승인:
- 검증:
```

- 영향: 기능 구현 전 작업자는 `09-devlog-mvp-spec.md`에서 해당 MVP 항목과 단계 순서를 확인해야 한다.

- 검증: 하네스 인덱스와 작업 흐름 계약에서 새 문서가 연결되는지 확인한다.
